# Pilot Onboarding Checklist

- Seed the demo or create the college environment
- Verify TPO login works
- Verify student login works
- Upload or import student roster
- Review upcoming drives and criteria
- Confirm at least 5 mock tests are active
- Confirm resources page is not empty
- Send first student reminder from Communication
- Walk TPO through Dashboard, Students, Drives, Communication
- Record first feedback call within 7 days
