# TPO Proof Track

This is the non-code pilot leverage track for turning one active college into proof for the next one.

## Product Output To Use

Use the report at:

- `TPO > Reports > Compliance > NAAC Placement Evidence Package`

This is the cleanest evidence export for a testimonial, admin review, or referral conversation.

## After 2-4 Weeks Of Usage

Ask for three things in this order.

### 1. Written testimonial
Use this exact prompt:

> If Smart Path has been useful so far, could you share 3-4 lines on what helped most in your placement workflow?

### 2. Name usage permission
Use this exact prompt:

> Can I mention your college name as an active pilot user when I speak to another placement officer?

### 3. One warm referral
Use this exact prompt:

> If you know one placement officer at another college who would benefit from this, could you make one introduction on WhatsApp or phone?

## What To Carry Into That Conversation

- latest NAAC evidence export
- one branch-wise placement report
- one screenshot of student readiness / practice activity
- short note on what changed after deployment

## Proof Pack Checklist

Before asking for a testimonial or referral, verify:

- reports export correctly
- the current college name appears correctly where needed
- student and drive data are current
- the TPO can see at least one report they would actually reuse

## Do Not Ask Too Early

Do not ask for testimonial/referral before:

- real student data is in the system
- one or more drives or announcements were actually managed
- the TPO has seen at least one useful report/export

## Goal

The point of this track is not a polished sales deck. The point is one real reference college and one credible introduction to the next one.
